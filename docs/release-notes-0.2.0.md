XD Suite is a free, bilingual home for independent Windows apps.

- Standalone XD Burner (German: XD Brenner), previously KlarBrand.
- Optional XD Suite launcher with installed-app discovery, search and update view.
- Independent installers, Start menu entries and uninstallers.
- German/English language menu with immediate switching and a saved preference.
- GitHub Release catalog, streamed downloads and SHA-256 verification before installation.
- Data CDs, MP3/WAV audio CDs, ISO export/burning and CD-RW erase through Windows IMAPI.

Windows 10/11, 64 bit. Both installers include .NET; no account, ads, trial or paid features. The installers are currently unsigned.

Validation: real IMAPI ISO creation/content hashes, audio conversion, bilingual UI and installation checks. Physical CD burning/erasure/read-back still requires validation with an actual burner.
