XD Suite und XD Brenner 0.3.0 für Windows 10/11 (64 Bit).

- Werbesprüche und Autorenzeile aus beiden Oberflächen entfernt. Deutsch und Englisch bleiben im Menü umschaltbar.
- Setups mit Administratorrechten und Sprachauswahl. Im Suite-Setup lässt sich XD Brenner direkt mitinstallieren oder abwählen. Beide Programme bleiben einzeln nutzbar.
- XD Suite prüft beim Start auf eine neue Suite-Version und fragt vor Download und Installation. Updates verwenden dieselbe Installation und starten keinen Deinstaller. Einstellungen und andere installierte Programme bleiben erhalten.
- Audio-CDs bleiben enthalten. Neu: OGG/Vorbis, Titel per Ziehen umordnen und Pausen von 2/3/5/10 Sekunden auswählen.
- Kapazitätsanzeige mit freiem bzw. überschrittenem Platz oder Laufzeit. Daten-CDs berücksichtigen den Dateisystembedarf.

**Downloads:** `XD-Suite-Setup-0.3.0.exe` enthält die Suite und den auswählbaren Brenner. `XD-Brenner-Setup-0.3.0.exe` installiert nur den Brenner. Vorhandene Versionen lassen sich direkt mit dem Setup aktualisieren.

Geprüft: IMAPI-ISO-Erstellung und Inhalte, MP3/WAV/OGG-Konvertierung, Audiopausen, Sprachwechsel, Download- und Updateprüfung sowie der echte Updatehelfer mit isolierten Installern. Der Updateversuch prüft ausdrücklich, dass kein Deinstaller läuft und Daten erhalten bleiben.

Die Setups sind noch unsigniert; Windows SmartScreen kann deshalb weiterhin warnen. Physisches Brennen und CD-RW-Löschen konnten hier mangels Laufwerk nicht geprüft werden.

XD Suite and XD Burner 0.3.0 for Windows 10/11 (64-bit).

- Removed slogans and the author byline. German and English remain selectable in the menu.
- Administrator installers with language selection. The suite setup can install the included burner as an optional component. Applications still run independently.
- Startup suite-update check with confirmation, verified downloads and in-place installation. No uninstaller is invoked; settings and other applications are retained.
- Audio CDs retained. Added OGG/Vorbis, drag reordering and selectable 2/3/5/10-second gaps.
- Capacity display shows free space or overrun, including actual file-system overhead for data CDs.

Install the new setup directly over an existing version. Installers remain unsigned and may trigger SmartScreen. Physical recording and CD-RW erasure still need testing on a real drive.
