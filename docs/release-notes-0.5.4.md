# XD Suite 0.5.4

- Horizontale Menüleiste und Programmansichten am oberen Fensterrand.
- Eigene grüne Symbole für die getrennten Beta-Installationen.
- Beta-Updates werden nach Version und Build-Kennung ausgewählt, auch wenn ältere CI-Läufe später fertig werden.
- Unveränderte Stable-Programme behalten ihre bisherigen Versionen und veröffentlichten Setups.

## English

- Horizontal menu bar and program views at the top of the window.
- Separate green icons identify independently installed beta applications.
- Beta updates use version and build order, including when older CI runs finish later.
- Unchanged stable applications retain their existing versions and published installers.
