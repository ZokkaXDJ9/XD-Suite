# XD Suite 0.5.0

XD Konverter ist jetzt in der Suite verfügbar. Er lässt sich im Suite-Setup auswählen, über die Suite nachinstallieren und unabhängig davon starten oder aktualisieren. Das eigene Setup installiert ihn unter Programme.

Der Konverter unterstützt MP3, WAV, FLAC, OGG/Vorbis, M4A/AAC und Opus. Alle Audiooptionen stehen zunächst auf Automatisch. Weitere Einstellungen für CBR, ABR, VBR, Abtastrate, Bittiefe, Kanalzahl und FLAC-Kompression sind optional. Originaldateien werden nicht überschrieben. Deutsch und Englisch sind im Menü wählbar.

| Bestandteil | Version |
| --- | --- |
| XD Suite | 0.5.0 |
| XD Konverter | 0.5.0 |
| XD Brenner | 0.4.1, unverändert |

Der Brenner erhält keine neue Version. Die Suite verwendet sein originales Setup 0.4.1 mit derselben Prüfsumme und installiert es nicht erneut, wenn diese oder eine neuere Version bereits vorhanden ist. Bestehende Installationen werden aktualisiert, ohne einen Deinstaller aufzurufen.

XD Converter is now available in the suite installer and launcher, with its own standalone installer. Audio settings default to Automatic; advanced settings are optional. XD Burner remains unchanged at 0.4.1, using its original installer. Existing installations are updated in place.
