XD Suite und XD Brenner 0.4.0 für Windows 10/11 (64 Bit).

- Die Setups verwenden Programme statt AppData. Vorhandene AppData-Installationen werden ohne Deinstaller verschoben und aktualisiert; Einstellungen und eigene Dateien bleiben erhalten.
- Die Schaltfläche Downloadquelle und die Repository-Konfiguration sind entfernt. Die Suite verwendet fest ZokkaXDJ9/XD-Suite auf GitHub.
- Audiopausen von 0, 1, 2, 3, 5 und 10 Sekunden. 0/1 Sekunde nutzt Disc-at-once und benötigt ein kompatibles Laufwerk. Audio-CDs bleiben vollständig enthalten.
- Weiterhin enthalten: Deutsch/Englisch im Menü, MP3/WAV/OGG, Titel per Ziehen umordnen, Kapazität und Überschreitung, Admin-Setup mit Sprachauswahl und auswählbarem Brenner, Suite-Update mit Rückfrage und ohne Deinstallation.

**Downloads:** XD-Suite-Setup-0.4.0.exe enthält Suite und auswählbaren Brenner. XD-Brenner-Setup-0.4.0.exe installiert nur den Brenner. Die vorhandene Version direkt mit dem neuen Setup aktualisieren.

Geprüft: echte IMAPI-ISO- und DAO-Image-Erstellung einschließlich 0/1-Sekunden-Titelgrenzen, Audiokonvertierung, Kapazität, Sprachen, Downloads, Updatehelfer sowie isolierte Setup- und Migrationstests. Kein Deinstalleraufruf beim Update oder beim Verschieben; Daten bleiben erhalten.

Die Setups sind unsigniert und können SmartScreen auslösen. Physisches Brennen und CD-RW-Löschen sind mangels Laufwerk noch nicht verifiziert.

XD Suite and XD Burner 0.4.0 for Windows 10/11 (64-bit).

- Installers use Program Files. Old AppData installations are relocated and updated without running an uninstaller, preserving settings and personal files.
- Removed the download-source button and repository settings. The official GitHub repository is fixed.
- Audio gaps of 0/1/2/3/5/10 seconds. Gaps below two seconds use Disc-at-once and require compatible hardware.
- Retains audio CDs, MP3/WAV/OGG, drag reordering, capacity/overrun, German/English, component selection and confirmed in-place suite updates.

Install the new setup over the current installation. Installers remain unsigned; actual disc writing and erasure still need testing on a real drive.
