# XD Suite 0.5.3

„Installiert“ zeigt jetzt stabile Programme und installierte Betas gemeinsam. Betas werden auch ohne gespeicherten Beta-Katalog lokal erkannt und können gestartet oder getrennt deinstalliert werden. Der stabile Programmkatalog bleibt unverändert getrennt.

Der Beta-Kanal umfasst zusätzlich XD Brenner und XD Konverter. Stable und Beta haben eigene Installationskennungen, Ordner, Prozesse und Einstellungen. Eine bereits installierte stabile Version verhindert die Installation einer gleich nummerierten Beta nicht. Weitere Builds derselben Beta-Version werden anhand der Build-Kennung erkannt.

Nur die Suite erhält 0.5.3. Die stabilen Programme bleiben unverändert bei 0.5.2 und verwenden ihre bisherigen Setups. Die neuen Brenner-/Konverter-Betas tragen 0.5.3-Beta; unveränderte Betas bleiben bei 0.5.2-Beta.

## English

Installed now includes stable applications and installed betas, with local/offline discovery even without a saved beta catalog. Each variant can be launched or uninstalled independently. The stable catalog remains separate.

Burner and Converter are now also available on the beta channel. Separate installer identities, folders, processes and settings allow a beta to be installed alongside an equally numbered stable version. Build metadata distinguishes subsequent builds of the same beta version. Only the suite changes to 0.5.3; unchanged stable applications retain their 0.5.2 versions and original installers.
