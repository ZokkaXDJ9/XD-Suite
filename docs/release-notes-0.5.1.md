# XD Suite 0.5.1

Installierte Programme können über den Button **Deinstallieren** in der Suite entfernt werden. Nach einer Rückfrage startet der registrierte Deinstaller. Bei Abbruch bleibt das Programm als installiert sichtbar; nach erfolgreicher Entfernung wird die Liste aktualisiert. Der Button und die Rückfrage unterstützen Deutsch und Englisch.

Die Updatefunktion aktualisiert weiterhin die vorhandene Installation ohne Deinstallation. XD Brenner bleibt unverändert bei **0.4.1**, XD Konverter bei **0.5.0**. Ihre bisherigen Setups und Prüfsummen werden weiterverwendet.

XD Suite now offers an **Uninstall** button for installed applications, with confirmation and automatic status refresh. Cancelling keeps the application installed. Updates still update the existing installation in place. XD Burner 0.4.1 and XD Converter 0.5.0 are unchanged and retain their original installers.
